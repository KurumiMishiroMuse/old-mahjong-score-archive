# 旧式麻雀点数表アーカイブ

戦前〜戦後期の実物の麻雀点数計算カード（実用新案特許 第589619号）を転記し、現代ルールの点数と並べて換算できるようにした資料ページです。

- `index.html` — 旧式⇔現代 麻雀点数換算表（ロン30〜70符／ツモ30〜80符の対照表、早見ルックアップ、解説メモ）

## この資料でわかる旧式ルールの特徴

- **場ゾロがない** — 基本点は「符 × 2^飜数」。現代の基本点（符 × 2^(飜数+2)）のちょうど4分の1で、100点単位への切り上げもなく、10点単位のままやり取りした。旧式の点数がきれいに割り切れるのはこのため。
- **満貫での打ち止め計算がない** — 表の範囲では生の計算値がそのまま載っている（例: 旧式4飜60符の子ロンは3840点）。
- **満貫が天井** — 役の格付けでは満貫が最高段で、現代では役満になる九連宝燈・大三元・四喜和・清老頭・字一色・四暗刻・十三幺九も、すべて「満貫」だった。現代の役満（満貫の4倍）やダブル役満と比べると、点数インフレの大きさがわかる。
- **七対子の点数が違う** — 荘家200点・散家100点を基礎点として、飜数ごとに倍々になる。現代の「25符固定・2飜」のような半端な扱いはない。
- **ピンフツモ** — 旧式のツモ表に20符の欄自体がなく、ピンフツモは「ツモのみ」として処理されていた（現代の20符2飜 400・700等より低くなる）。
- **十三幺九** — 国士無双は当時この名で載っている。中国の別物の手「十三不搭」と伝わる過程で混ざり合い、十三不搭の方はローカル役に落ちた。

## 出典と注記

- 旧式側の数値は、所蔵する実物カードの「投了栄（ロン）」「自摸栄（ツモ）」両表および役一覧からの転記です（ロン表は70符まで、ツモ表は80符まで）。
- 現代側の数値は、現行の標準的な計算式（場ゾロ込み、100点単位切り上げ、満貫打ち止め）で算出しました。
- 支払い方法などの運用面は、カード所蔵者の記憶と解説に基づく復元を含みます。

麻雀の点数制度の歴史資料として、個人所蔵の実物から起こした一次転記です。
